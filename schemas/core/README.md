# Core schemas

领域无关记录的版本化 JSON Schema。

已实现：`research-task/v1`、`research-claim/v1`、`research-evidence/v1`（见 `docs/architecture/core-interface.md`）。

计划中但未实现：Run、FailureObservation、FailureAnalysis、ResearchCasePackage、EvaluationCase、CandidateBundle、PromotionDecision。这些条目仍是空白契约，不表示 schema 已实现。ExperiencePacket 已定性为 Experience Exporter 的派生产物，不作为 Core schema（ADR-0003 决策 9）。
